# ⚡ Photoelectric Effect 3D Simulation

An interactive 3D educational project that demonstrates the **Photoelectric Effect** using Three.js.  
It combines physics visualization + presentation slides in a single web-based experience.

- 📚 Slide-based learning system
- 🧪 3D experimental setup (cathode, anode, tube)

## 🧠 Physics Concept

This project demonstrates the **Photoelectric Effect**:

- Light consists of photons (energy packets)
- Photons hit a metal surface
- If energy ≥ threshold frequency → electrons are emitted
- Emitted electrons create electric current

Key equation:
\[
E = hf
\]

Where:
- E = photon energy  
- h = Planck’s constant  
- f = frequency of light
